KAVYABALA — MULTI-PAGE PORTFOLIO
================================

PAGES
- index.html     Home
- about.html     About
- skills.html    Skills
- projects.html  Projects
- contact.html   Contact
- style.css      Responsive styling
- script.js      Mobile navigation and demo form feedback

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html (or right-click > Open with > Chrome).
4. Use the navigation menu to visit the other pages.

ACCESSIBILITY FEATURES
- Semantic header, nav, main, section and footer elements
- Skip-to-content link
- Descriptive page titles and meta descriptions
- Keyboard-visible focus indicators
- Mobile navigation button with aria-expanded and aria-controls
- Contact form labels, required fields and live status message
- Reduced-motion preference support
- Responsive layout

BEFORE SUBMITTING
- Replace the sample project descriptions with your actual work.
- Add your preferred email address and real contact details.
- Add your GitHub / LinkedIn links if you want them displayed.
- The contact form is front-end only; it does not send messages until connected to a backend or form service.
- The design uses Google Fonts when internet is available; fallback fonts are included.
